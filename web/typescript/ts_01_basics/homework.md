# ДЗ TS 1 — Типизация данных

Свои решения клади в папку `solution/`.

---

## Задание

Типизируй набор функций и переменных. Никакого `any`.

### 1. Переменные

Объяви переменные с правильными типами:

```ts
// Заверши объявления
const username = ???
const score = ???
const isActive = ???
const tags = ???        // массив строк
const coords = ???      // tuple: [широта, долгота] — два числа
```

### 2. Union-тип для статуса

```ts
// Создай тип OrderStatus с вариантами: 'pending', 'processing', 'shipped', 'delivered', 'cancelled'
// Напиши функцию getStatusLabel(status: OrderStatus): string
// Каждый статус должен возвращать читаемый текст на русском
```

### 3. Сужение типов (type narrowing)

```ts
// Напиши функцию formatId(id: string | number): string
// Если id — число, вернуть '#' + id (например: '#42')
// Если id — строка, вернуть id в верхнем регистре
```

### 4. Функция с unknown

```ts
// Напиши функцию safeLength(value: unknown): number
// Если value — строка, вернуть её длину
// Если value — массив, вернуть его длину
// Иначе вернуть 0
```

---

## Требования

- [ ] Нигде нет `any`
- [ ] Все функции имеют явные типы параметров и возвращаемого значения
- [ ] `formatId` и `safeLength` работают корректно для всех случаев
