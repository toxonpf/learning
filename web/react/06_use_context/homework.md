# ДЗ 6 — Тема и авторизация

Свои решения клади в папку `solution/`.

---

## Задание

Создай приложение с двумя контекстами: `ThemeContext` и `AuthContext`.

### ThemeContext:
- Хранит тему: `'light' | 'dark'`
- Предоставляет функцию `toggleTheme`
- Применяет тему через CSS-переменные или inline-стили

### AuthContext:
- Хранит: `user: { name: string; role: 'admin' | 'user' } | null`
- Предоставляет `login(name, role)` и `logout()`

### Компоненты приложения:

**`Header`** — показывает имя пользователя или «Гость», кнопку входа/выхода, кнопку смены темы

**`LoginForm`** — форма с полем имени и выбором роли (показывается только если `user === null`)

**`Dashboard`** — приветствие (показывается только если залогинен)

**`AdminPanel`** — панель (показывается только если `role === 'admin'`)

---

## Требования

- [ ] Оба контекста реализованы с кастомными хуками (`useTheme`, `useAuth`)
- [ ] При смене темы меняется фон и цвет текста всего приложения
- [ ] После логина `LoginForm` скрывается, появляется `Dashboard`
- [ ] `AdminPanel` видна только для роли `admin`
- [ ] После logout всё сбрасывается

---

## Бонус

- Сохранять тему в `localStorage` и восстанавливать при перезагрузке
- Сохранять пользователя в `sessionStorage`
