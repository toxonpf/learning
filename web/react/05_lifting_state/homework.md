# ДЗ 5 — Магазин с корзиной

Свои решения клади в папку `solution/`.

---

## Задание

Создай мини-магазин из трёх компонентов, где состояние поднято в `Shop`.

### Компоненты:

**`ProductList`** — список товаров с кнопкой «В корзину»

**`Cart`** — корзина с товарами и итоговой суммой

**`Shop`** — родитель, хранит состояние корзины

### Данные товаров:

```tsx
const PRODUCTS: Product[] = [
  { id: 1, name: 'Ноутбук', price: 50000 },
  { id: 2, name: 'Мышь', price: 1500 },
  { id: 3, name: 'Клавиатура', price: 3000 },
  { id: 4, name: 'Монитор', price: 25000 },
  { id: 5, name: 'Наушники', price: 5000 },
];
```

---

## Требования

- [ ] Весь стейт корзины хранится только в `Shop`
- [ ] `ProductList` получает только `products` и `onAdd`
- [ ] `Cart` получает только `items` и `onRemove`
- [ ] Нельзя добавить один товар дважды (кнопка становится неактивной)
- [ ] В корзине показывается итоговая сумма
- [ ] Кнопка «Оформить» очищает корзину

---

## Бонус

- Счётчик количества товара (добавить/убрать штуку)
- Кнопка «Очистить корзину»
- Сортировка товаров по цене
