# ДЗ 4 — Форма регистрации

Свои решения клади в папку `solution/`.

---

## Задание

Создай компонент `RegistrationForm` — многошаговую форму регистрации.

### Шаг 1 — Личные данные:
- Имя (обязательно, мин. 2 символа)
- Фамилия (обязательно)
- Дата рождения (обязательно)

### Шаг 2 — Аккаунт:
- Email (обязательно, должен содержать `@`)
- Пароль (обязательно, мин. 8 символов)
- Подтверждение пароля (должно совпадать с паролем)

### Шаг 3 — Подтверждение:
- Показать введённые данные (кроме пароля)
- Чекбокс «Согласен с условиями»
- Кнопка «Зарегистрироваться»

---

## Требования

- [ ] Кнопка «Далее» не переходит на следующий шаг при ошибках валидации
- [ ] Ошибки показываются под каждым полем
- [ ] Кнопка «Назад» возвращает к предыдущему шагу с сохранёнными данными
- [ ] На шаге 3 кнопка «Зарегистрироваться» заблокирована без чекбокса
- [ ] После отправки показать сообщение «Успешно зарегистрирован!»

---

## Бонус

- Показывать прогресс-бар шагов (1 / 2 / 3)
- Поле пароля: кнопка «показать/скрыть»
