# ДЗ 1 — Карточка профиля

Свои решения клади в папку `solution/`.

---

## Задание

Создай компонент `ProfileCard`, который принимает props и отображает карточку пользователя.

### Что должно быть в карточке:

- Имя пользователя
- Возраст
- Список хобби (массив строк)
- Статус — онлайн или офлайн

### Props компонента:

```tsx
type ProfileCardProps = {
  name: string;
  age: number;
  hobbies: string[];
  isOnline: boolean;
};
```

### Пример использования:

```tsx
<ProfileCard
  name="Алексей"
  age={25}
  hobbies={['Программирование', 'Чтение', 'Игры']}
  isOnline={true}
/>
```

### Ожидаемый результат:

```
┌─────────────────────────┐
│ 🟢 Алексей, 25 лет      │
│                         │
│ Хобби:                  │
│  • Программирование     │
│  • Чтение               │
│  • Игры                 │
└─────────────────────────┘
```

---

## Требования

- [ ] Компонент называется `ProfileCard`
- [ ] Props описаны через `type ProfileCardProps`
- [ ] Имя и возраст выводятся в одной строке
- [ ] Список хобби рендерится через `.map()` с `key`
- [ ] Статус меняется в зависимости от `isOnline`
- [ ] Если хобби нет (`[]`) — вывести текст `"Хобби не указаны"`
