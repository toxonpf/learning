# ДЗ 9 — Блог с роутингом

Свои решения клади в папку `solution/`.

---

## Задание

Создай мини-блог с несколькими страницами.

### Страницы:

| Путь | Компонент | Описание |
|------|-----------|----------|
| `/` | `HomePage` | Список последних постов |
| `/posts` | `PostsPage` | Все посты с фильтром по категории |
| `/posts/:id` | `PostPage` | Один пост + список комментариев |
| `/about` | `AboutPage` | Статичная страница |
| `*` | `NotFoundPage` | 404 |

### Данные (JSONPlaceholder):

- Посты: `https://jsonplaceholder.typicode.com/posts`
- Один пост: `https://jsonplaceholder.typicode.com/posts/:id`
- Комментарии: `https://jsonplaceholder.typicode.com/posts/:id/comments`

---

## Требования

- [ ] Навигация через `<Link>` без перезагрузки страницы
- [ ] При клике на пост — переход на `/posts/:id`
- [ ] На странице поста загружаются комментарии отдельным запросом
- [ ] Фильтр на `/posts` работает через `useSearchParams` (URL: `/posts?userId=1`)
- [ ] `Layout` с шапкой и навигацией вынесен через вложенные маршруты + `<Outlet>`
- [ ] Страница 404 для неизвестных путей

---

## Бонус

- `<NavLink>` с подсветкой активного пункта навигации
- Хлебные крошки на странице поста
- Кнопка «Назад» через `useNavigate(-1)`
