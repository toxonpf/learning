# ДЗ 0 — Запуск sandbox

---

## Задание

Запусти учебный проект и убедись что он работает.

---

## Шаги

### 1. Установи зависимости

```
cd sandbox
npm install
```

### 2. Запусти дев-сервер

```
npm run dev
```

Открой [http://localhost:5173](http://localhost:5173).

### 3. Проверь что всё работает

- В боковой панели видны уроки 01–10
- Клик на урок показывает компонент справа
- Страница обновляется автоматически при сохранении файлов

### 4. Проверь типы

```
npm run typecheck
```

Нет ошибок — всё настроено правильно.

---

## Требования

- [ ] `npm install` завершился без ошибок
- [ ] Страница открывается на `localhost:5173`
- [ ] Боковое меню с уроками отображается
- [ ] `npm run typecheck` завершается без ошибок
