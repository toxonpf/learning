# ДЗ 2 — Список задач (Todo)

Свои решения клади в папку `solution/`.

---

## Задание

Создай компонент `TodoList` — минимальный менеджер задач.

### Функциональность:

- Добавить задачу через поле ввода и кнопку
- Отметить задачу выполненной (зачёркнутый текст)
- Удалить задачу
- Показать счётчик: сколько задач осталось невыполненных

### Пример структуры данных:

```tsx
interface Todo {
  id: number;
  text: string;
  done: boolean;
}
```

### Ожидаемый результат:

```
[ Купить молоко         ] [Добавить]

☑ ~~Купить молоко~~     [Удалить]
☐ Сходить в спортзал    [Удалить]
☐ Прочитать книгу       [Удалить]

Осталось: 2 задачи
```

---

## Требования

- [ ] Поле ввода очищается после добавления задачи
- [ ] Нельзя добавить пустую задачу
- [ ] Клик по задаче переключает `done`
- [ ] Кнопка удаления убирает задачу из списка
- [ ] Счётчик обновляется реактивно

---

## Бонус

- Кнопка «Очистить выполненные» — удаляет все задачи с `done: true`
- Фильтры: Все / Активные / Выполненные
