# ДЗ 3 — Поиск пользователей

Свои решения клади в папку `solution/`.

---

## Задание

Создай компонент `UserSearch` — поиск пользователей через публичное API.

**API:** `https://jsonplaceholder.typicode.com/users`

### Функциональность:

- При монтировании загрузить список всех пользователей
- Показывать состояние загрузки
- Фильтровать пользователей по имени (поле ввода)
- При клике на пользователя загружать его посты отдельным запросом
- Отменять предыдущий запрос при смене пользователя (AbortController)

### Структура данных:

```tsx
interface User {
  id: number;
  name: string;
  email: string;
}

interface Post {
  id: number;
  title: string;
}
```

**Посты пользователя:** `https://jsonplaceholder.typicode.com/posts?userId={id}`

---

## Требования

- [ ] Загрузка пользователей при монтировании (`[]`)
- [ ] Показывается спиннер/текст во время загрузки
- [ ] Фильтрация по имени работает без нового запроса (фильтруем локально)
- [ ] Клик по пользователю загружает его посты
- [ ] Используется `AbortController` для отмены запроса постов
- [ ] При смене пользователя показывается загрузка постов

---

## Бонус

- Дебаунс на поле поиска (300мс) — не фильтровать при каждом символе
- Обработка ошибок сети с сообщением пользователю
