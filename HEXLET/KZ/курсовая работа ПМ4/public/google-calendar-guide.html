Подключение Google Календаря

  1. В проекте Google Cloud включите Google Calendar API.
  2. Настройте экран согласия OAuth и создайте идентификатор клиента типа «Веб-приложение». Для приложения в режиме тестирования добавьте нужные Google-аккаунты в список тестовых пользователей.
  3. Добавьте разрешённый URI перенаправления http://127.0.0.1:3000/integrations/google-calendar/callback. Для развёрнутого приложения используйте его HTTPS-адрес с тем же путём.
  4. В .env укажите GOOGLE_CALENDAR_CLIENT_ID, GOOGLE_CALENDAR_CLIENT_SECRET и GOOGLE_CALENDAR_REDIRECT_URI, затем перезапустите сервер. Откройте платформу на том же адресе, что указан в URI перенаправления.
  5. Откройте «Расписание», нажмите «Google Календарь», подключите личный аккаунт и подтвердите доступ. В Google появится отдельный календарь «Учебное расписание».

Автоматическое обновление идёт из платформы в Google. Через кнопку «Синхронизировать сейчас» можно запросить обновление вручную. После отключения уже перенесённые события остаются в созданном календаре.
