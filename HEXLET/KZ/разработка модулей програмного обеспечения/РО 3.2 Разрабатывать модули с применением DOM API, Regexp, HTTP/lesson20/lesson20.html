Лабораторная работа № 20: Перенаправления, HTTPS и современные версии HTTP

1. Перенаправления (3xx)

Браузер автоматически следует по перенаправлениям. Ниже — результаты из DevTools и curl.

Результаты наблюдений в DevTools → Network:

URL Код ответа Значение Location (куда редиректит) Конечный URL
http://hexlet.io 301 Moved Permanently https://hexlet.io/ https://hexlet.io/
http://github.com 301 Moved Permanently https://github.com/ https://github.com/

Результаты curl -I:

curl -I http://yandex.kz/
HTTP/1.1 301 Moved Permanently
Location: https://yandex.kz/
...

curl -I http://youtube.com
HTTP/1.1 301 Moved Permanently
Location: https://www.youtube.com/
...

Пояснение: оба сервера возвращают 301 (постоянное перенаправление),
указывая в заголовке Location новый HTTPS-адрес.
Браузер автоматически делает новый запрос по этому адресу.
Нажмите кнопку...

2. HTTPS и сертификаты

DevTools → Security — hexlet.io:

ПараметрЗначение
Кем выданLet's Encrypt (R10 / R11)
Для доменаhexlet.io, *.hexlet.io
Срок действия~90 дней (автообновление)

Ненадёжные сайты (badssl.com):

СайтПроблемаПричина недоверия
self-signed.badssl.com Самоподписанный сертификат Сертификат не выдан доверенным CA — браузер не может проверить подлинность сервера
expired.badssl.com Сертификат просрочен Срок действия сертификата истёк — соединение может быть небезопасным

3. HTTP/1.1 vs HTTP/2 vs HTTP/3

DevTools → Network → включить колонку Protocol.
ВерсияОбозначениеОсобенности
HTTP/1.1http/1.1Одно соединение — один запрос, keep-alive
HTTP/2h2Мультиплексирование, сжатие заголовков, одно TCP-соединение
HTTP/3h3Основан на QUIC/UDP, меньше задержек
