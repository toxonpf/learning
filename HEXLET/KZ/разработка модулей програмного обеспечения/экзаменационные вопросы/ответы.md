### 1.1 Что такое программа и алгоритм

**Алгоритм** — конечная последовательность чётко определённых шагов для решения задачи.  
**Программа** — запись алгоритма на конкретном языке программирования, которую понимает компьютер.

```python
# Python — алгоритм нахождения максимума
a = 5
b = 10
if a > b:
    max_val = a
else:
    max_val = b
print(max_val)  # 10
```

```javascript
// JavaScript
let a = 5, b = 10;
let maxVal = a > b ? a : b;
console.log(maxVal); // 10
```

```csharp
// C#
int a = 5, b = 10;
int maxVal = a > b ? a : b;
Console.WriteLine(maxVal); // 10
```

### 1.2 Основные этапы разработки программы

1. **Анализ** — понять задачу, определить входные/выходные данные
2. **Проектирование** — составить алгоритм, выбрать структуры данных
3. **Написание кода** — реализовать алгоритм на языке программирования
4. **Тестирование** — проверить работу программы на разных данных
5. **Отладка** — найти и исправить ошибки
6. **Документирование** — описать работу программы

---

### 1.3 Что такое язык программирования и какие типы языков существуют

**Язык программирования** — формальный язык для записи алгоритмов, понятный компьютеру.

**Типы по уровню абстракции:**
- **Низкоуровневые** — Assembler (близко к железу)
- **Высокоуровневые** — Python, JS, C# (близко к человеку)

**Типы по способу выполнения:**
- **Компилируемые** — C, C++, C# (код → машинный код заранее)
- **Интерпретируемые** — Python, JavaScript (код выполняется построчно)
- **Смешанные** — Java, C# (компилируются в байт-код, затем интерпретируются виртуальной машиной)

**Типы по парадигме:**
- **Процедурные** — C, Pascal
- **Объектно-ориентированные** — C#, Java
- **Функциональные** — Haskell, Erlang
- **Мультипарадигменные** — Python, JavaScript, C#

---

### 1.4 Компилятор и интерпретатор: различия

| | Компилятор | Интерпретатор |
|---|---|---|
| Перевод | Весь код сразу | Построчно во время выполнения |
| Скорость | Быстрее при выполнении | Медленнее при выполнении |
| Ошибки | Все до запуска | По ходу выполнения |
| Примеры | C#, C++ | Python, JS (Node.js) |

> **C#** — компилируется в байт-код (IL), затем JIT-компилятор переводит в машинный код.  
> **JavaScript** — изначально интерпретировался, современные движки (V8) используют JIT.  
> **Python** — интерпретатор, но компилирует в байт-код (.pyc).

```python
# Python
x = 10          # переменная

```

```javascript
var old = 5;    // устаревший способ объявления переменной
```

```csharp

readonly int maxSize = 100;  // readonly — нельзя изменить после конструктора
```

### 1.9 Понятие выражения и оператора

**Выражение** — конструкция, которая вычисляется и возвращает значение: `2 + 3`, `x > 0`, `"Hi"`.  
**Оператор** — инструкция, которая выполняет действие: присваивание, вызов функции, ветвление.

```python
# Python
# Выражения:
2 + 3           # арифметическое
x > 0           # логическое
"Hi" + "!"      # строковое

# Операторы:
x = 10          # оператор присваивания
print(x)        # оператор вызова
if x > 0:       # условный оператор
    pass
```

```javascript
// JavaScript
// Выражения:
2 + 3           // 5
x > 0           // true/false
"Hi" + "!"      // "Hi!"
x++             // выражение с побочным эффектом

// Операторы:
let x = 10;    // оператор объявления/присваивания
console.log(x); // оператор-выражение
if (x > 0) {}  // условный оператор
```

```csharp
// C#
// Выражения:
int val = 2 + 3;         // 5
bool check = x > 0;      // true/false
string msg = "Hi" + "!"; // "Hi!"

// Операторы:
int x = 10;              // оператор объявления
Console.WriteLine(x);    // оператор-выражение
if (x > 0) { }           // условный оператор
```

### 1.10 Приоритет операций

От высшего к низшему (аналогично математике):

| Приоритет | Операции |
|-----------|----------|
| 1 (высший) | `()` скобки |
| 2 | `**` (степень, Python) |
| 3 | `*`, `/`, `//`, `%` |
| 4 | `+`, `-` |
| 5 | `<`, `>`, `<=`, `>=`, `==`, `!=` |
| 6 | `not` / `!` |
| 7 | `and` / `&&` |
| 8 (низший) | `or` / `\|\|` |

```python
# Python
result = 2 + 3 * 4      # 14, не 20 (умножение раньше)
result = (2 + 3) * 4    # 20 — скобки меняют порядок
result = 2 ** 3 ** 2    # 512 (3**2=9, 2**9=512) — степень правоассоциативна
print(True or False and False)  # True (and раньше or)
```

```javascript
// JavaScript
let r1 = 2 + 3 * 4;        // 14
let r2 = (2 + 3) * 4;      // 20
let r3 = true || false && false; // true (&&  раньше ||)
console.log(2 ** 3 ** 2);  // 512
```

```csharp
// C#
int r1 = 2 + 3 * 4;           // 14
int r2 = (2 + 3) * 4;         // 20
bool r3 = true || false && false; // true (&& раньше ||)
double r4 = Math.Pow(2, Math.Pow(3, 2)); // 512
```

### 2.3 Полная и неполная форма условного оператора

**Неполная форма** — только `if` (действие только при истине).  
**Полная форма** — `if-else` (действие и при истине, и при лжи).

```python
# Python — неполная
if x > 0:

if x > 0:
    print("положительное")
else:
    print("не положительное")

# Python — цепочка
if x > 0:
    print("положительное")
elif x < 0:
    print("отрицательное")
else:
    print("ноль")
```

### 3.1 Понятие цикла в программировании

**Цикл** — конструкция, позволяющая многократно выполнять блок кода. Используется когда нужно повторить действие определённое количество раз или пока выполняется условие.

---

### 3.2 Цикл for и его назначение

Цикл `for` используется когда **количество итераций известно заранее** или нужно перебрать элементы коллекции.

```python
# Python — перебор диапазона
for i in range(5):          # 0, 1, 2, 3, 4
    print(i)

# Перебор списка
fruits = ["яблоко", "банан", "вишня"]
for fruit in fruits:
    print(fruit)

# range с шагом
for i in range(0, 10, 2):  # 0, 2, 4, 6, 8
    print(i)
```

```javascript
// JavaScript — классический for
for (let i = 0; i < 5; i++) {
    console.log(i);         // 0, 1, 2, 3, 4
}

// Перебор массива
let fruits = ["яблоко", "банан", "вишня"];
for (let fruit of fruits) {
    console.log(fruit);
}

// for...in — перебор ключей объекта
let obj = { a: 1, b: 2 };
for (let key in obj) {
    console.log(key, obj[key]);
}
```

```csharp
// C# — классический for
for (int i = 0; i < 5; i++)
{
    Console.WriteLine(i);  // 0, 1, 2, 3, 4
}

// foreach — перебор коллекции
string[] fruits = { "яблоко", "банан", "вишня" };
foreach (string fruit in fruits)
{
    Console.WriteLine(fruit);
}
```

### 3.3 Цикл while и его особенности

Цикл `while` выполняется **пока условие истинно**. Используется когда количество итераций неизвестно заранее.

```python
# Python
count = 0
while count < 5:
    print(count)
    count += 1

# do-while аналог в Python (через while True + break)
while True:

    if user_input.isdigit():

```

```javascript
// JavaScript
let count = 0;
while (count < 5) {

    count++;
}

// do-while — выполняется минимум один раз
let n = 0;
do {
    console.log(n);
    n++;
} while (n < 5);
```

```csharp
// C#
int count = 0;
while (count < 5)
{
    Console.WriteLine(count);
    count++;
}

// do-while
int n = 0;
do
{
```

### 3.4 Различия между циклами for и while

| | `for` | `while` |
|---|---|---|
| Когда использовать | Известно количество итераций | Условие завершения |
| Счётчик | Встроен в синтаксис | Нужно управлять вручную |
| Риск бесконечного цикла | Низкий | Высокий |
| Перебор коллекций | Удобно | Неудобно |

```python
# for — когда знаем количество
for i in range(10):
    print(i)

# while — когда не знаем количество
import random
total = 0
while total < 100:
    total += random.randint(1, 20)
print(f"Финальная сумма: {total}")
```

```javascript
// for — перебор массива
let arr = [1, 2, 3, 4, 5];
for (let i = 0; i < arr.length; i++) {
    console.log(arr[i]);
}

// while — чтение до условия
let total = 0;
while (total < 100) {
    total += Math.floor(Math.random() * 20) + 1;
}
console.log(`Финальная сумма: ${total}`);
```

```csharp
// for — перебор массива
int[] arr = { 1, 2, 3, 4, 5 };
for (int i = 0; i < arr.Length; i++)
{
    Console.WriteLine(arr[i]);
}

// while — накопление до условия
Random rnd = new Random();
int total = 0;
while (total < 100)
{
    total += rnd.Next(1, 21);
}
Console.WriteLine($"Финальная сумма: {total}");
```

### 3.5 Управление циклом (break, continue)

**`break`** — немедленно прерывает цикл.  
**`continue`** — пропускает текущую итерацию, переходит к следующей.

```python
# Python
# break — найти первое чётное число
for i in range(10):
    if i % 2 == 0 and i > 0:
        print(f"Первое чётное > 0: {i}")
        break

# continue — пропустить нечётные
for i in range(10):
    if i % 2 != 0:
        continue
    print(i)  # 0, 2, 4, 6, 8
```

```javascript
// JavaScript
// break
for (let i = 0; i < 10; i++) {
    if (i === 5) {
        console.log("Стоп на", i);
        break;
    }
    console.log(i);  // 0, 1, 2, 3, 4
}

// continue — пропустить нечётные
for (let i = 0; i < 10; i++) {
    if (i % 2 !== 0) continue;
    console.log(i);  // 0, 2, 4, 6, 8
}
```

```csharp
// C#
// break
for (int i = 0; i < 10; i++)
{
    if (i == 5)
    {
        Console.WriteLine($"Стоп на {i}");
        break;
    }
    Console.WriteLine(i);
}
```

### 4.4 Срезы списков

**Срез** — извлечение подпоследовательности элементов. Синтаксис: `[начало:конец:шаг]`.

### 5.1 Что такое функция и зачем она используется

**Функция** — именованный блок кода, выполняющий конкретную задачу, который можно вызывать многократно.

### 5.3 Параметры и аргументы функции

**Параметр** — переменная в определении функции.  
**Аргумент** — значение, которое передаётся при вызове.

```python
# Python
def add(a, b):           # a, b — параметры
    return a + b

result = add(3, 5)       # 3, 5 — аргументы

# Параметры по умолчанию
def power(base, exp=2):
    return base ** exp

print(power(3))     # 9  (exp=2 по умолчанию)
print(power(3, 3))  # 27

# Именованные аргументы
print(power(exp=3, base=2))  # 8

# Произвольное количество аргументов
def total(*args):
    return sum(args)

print(total(1, 2, 3, 4))  # 10
```

```javascript
// JavaScript
function add(a, b) {      // параметры
    return a + b;
}
let result = add(3, 5);   // аргументы

    return base ** exp;
}

console.log(power(3, 3)); // 27

// Произвольное количество через rest

    return args.reduce((a, b) => a + b, 0);

```

```csharp

```

### 5.4 Возвращаемые значения функций

```python

lo, hi = min_max([3, 1, 4, 1, 5, 9])

```

```javascript
// Без return — undefined
```

```csharp
// void — ничего не возвращает
```

### 5.5 Преимущества использования функций

1. **Повторное использование** — написали один раз, вызываем много раз
2. **Читаемость** — код разбит на именованные части
3. **Модульность** — каждая функция отвечает за одно действие
4. **Тестируемость** — функцию легко протестировать отдельно
5. **Уменьшение ошибок** — логика в одном месте, не дублируется

```python

area3 = 3.14159 * 7 * 7

# С функцией — чисто и надёжно
import math
def circle_area(r):
    return math.pi * r ** 2

area1 = circle_area(5)
area2 = circle_area(10)
area3 = circle_area(7)
```

```javascript
function shuffle(array) {
```

### 8.2 Режимы открытия файлов

### 9.4 Использование finally

Блок `finally` выполняется **всегда** — независимо от того, было ли исключение. Используется для освобождения ресурсов (закрытие файлов, соединений с БД).

```python
# Python
f = None
try:
    f = open("file.txt", "r")
    content = f.read()
    print(content)
except FileNotFoundError:
    print("Файл не найден!")
finally:
    if f:
        f.close()           # выполняется всегда!
    print("Блок finally выполнен")
```

```javascript
// JavaScript
let connection = null;
try {
    connection = openConnection(); // условный пример
    connection.query("SELECT ...");
} catch (err) {
    console.error("Ошибка:", err.message);
} finally {
    if (connection) connection.close(); // всегда закрываем
    console.log("Finally выполнен");
}
```


### 9.5 Преимущества обработки исключений

1. **Программа не падает** — корректно сообщает об ошибке
2. **Разделение логики и обработки ошибок** — основной код чистый
3. **Разные реакции** — разные исключения → разная обработка
4. **Гарантированная очистка** — `finally` освобождает ресурсы
5. **Информативность** — пользователь видит понятное сообщение, а не стек вызовов

### 10.8 Основные ошибки начинающих программистов

| Ошибка | Пример | Решение |
|---|---|---|
| Опечатки в именах | `pritn()` вместо `print()` | Использовать IDE с автодополнением |
| Путаница `=` и `==` | `if x = 5` | Помнить: `=` присваивание, `==` сравнение |
| Индекс за пределами | `lst[len(lst)]` | Последний элемент: `lst[len(lst)-1]` |
| Бесконечный цикл | Забыть обновить счётчик | Проверять условие выхода |
| Деление на ноль | `x / 0` | Проверять делитель перед делением |
| Изменение типа | `"5" + 5` | Явно преобразовывать типы |

```python
# Типичные ошибки Python

# 1. = вместо ==
x = 5
if x == 5:  # правильно
    print("пять")

# 2. IndentationError
def func():
    return 1   # правильный отступ (4 пробела)

# 3. Изменение списка во время итерации
lst = [1, 2, 3, 4, 5]
# Неправильно:
# for i in lst:
#     if i % 2 == 0: lst.remove(i)

# Правильно:
lst = [i for i in lst if i % 2 != 0]

# 4. Мутабельный аргумент по умолчанию
def append_to(element, to=None):   # правильно
    if to is None:
        to = []
    to.append(element)
    return to
```

### 10.9 Документирование программ

**Документация** — описание того, как работает программа: что делает, как использовать, какие параметры принимает.

```python
# Python — docstrings (PEP 257)
def calculate_bmi(weight_kg, height_m):
    """
    Вычисляет индекс массы тела (ИМТ).
    
    Args:
        weight_kg (float): вес в килограммах
        height_m (float): рост в метрах
    
    Returns:
        float: значение ИМТ
    
    Raises:
        ValueError: если рост или вес <= 0
    
    Example:
        >>> calculate_bmi(70, 1.75)
        22.86
    """
    if weight_kg <= 0 or height_m <= 0:
        raise ValueError("Рост и вес должны быть положительными")
    return weight_kg / height_m ** 2
```

### 10.10 Основные принципы написания качественного кода

**1. DRY — Don't Repeat Yourself** (Не повторяй себя)

```python
# Плохо — дублирование
area_circle1 = 3.14 * 5 * 5
area_circle2 = 3.14 * 10 * 10

# Хорошо
import math
def circle_area(r): return math.pi * r ** 2
```

**2. KISS — Keep It Simple, Stupid** (Пиши просто)

```python
# Сложно
def is_even(n):
    if n % 2 == 0:
        return True
    else:
        return False

# Просто
def is_even(n):
    return n % 2 == 0
```

**3. Принцип единственной ответственности** — одна функция делает одно дело

```javascript
// Плохо — функция делает всё
function processUser(user) {
    // валидация + сохранение + отправка письма
}

// Хорошо
function validateUser(user) { /* только валидация */ }
function saveUser(user) { /* только сохранение */ }
function sendWelcomeEmail(user) { /* только письмо */ }
```

**4. Понятные имена**

```csharp
// Плохо
int d = 86400;
bool chk(int x) => x > 18;

// Хорошо
int secondsInDay = 86400;
bool IsAdult(int age) => age >= 18;
```

**5. Ранний возврат (Guard Clauses)**

```python
# Плохо — глубокая вложенность
def process(user):
    if user is not None:
        if user.is_active:
            if user.age >= 18:
                return "OK"

# Хорошо — ранние проверки
def process(user):
    if user is None: return "Нет пользователя"
    if not user.is_active: return "Пользователь неактивен"
    if user.age < 18: return "Несовершеннолетний"
    return "OK"
```
